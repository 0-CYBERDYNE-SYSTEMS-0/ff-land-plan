# BETA-02A crop model and evidence decision record

Status: source-backed decision and evidence baseline reviewed; explicit model dispatch and a qualified v2 daily path are implemented for complete frozen inputs; source-backed executable parameter coverage and acceptance remain incomplete. No candidate comparisons have been run.
Prepared: 2026-10-27
Scope: BETA-02A only. This record does not claim horticultural validation.

## Baseline inspected

The current daily reducer is deterministic and replays from `RunConfig` plus frozen `envSeries`. Before this work, `modelInputs.model: 'run-inputs-v1'` already existed as a serialized input-shape tag; it did not identify the crop equations or parameter set. `cropModelVersion` is the separate discriminator added by this stage. Legacy records may omit `modelInputs`; `engine.ts` then falls back to caller context or today’s crop catalog. Existing development is run-window normalized in `drivers.ts` (`growthDays × meanDailyGddC`), biomass is `gddAccum / gddRequired`, the water bucket uses a universal 30 cm root depth, and catalog yield is paid independently of accumulated dry matter. `DailyEnvironment` may include natural DLI; enclosure climate can combine natural and installed DLI, while `dliAvailable` distinguishes unknown light from known zero.

The current `cropThermalParams.ts` has nine crop entries. It is useful source evidence, but does not yet cover production, root-zone, nutrient, cultivar, or every catalog parameter. `growth.ts` remains a second calendar-day projection path and must be labelled/kept separate until its consumers are migrated.

## Decisions

### D1. Keep a pure local daily model and use explicit model dispatch

Implement a new crop-model version in the existing TypeScript reducer. Keep `stepDay`, `simulateRun`, frozen environment series, and the existing storage/API seams. Do not add a Python runtime, server requirement, worker framework, or second run store.

Each new run must freeze both a named model version and the complete parameter/input version it consults. Dispatch is explicit:

| Stored record | Replay behavior |
|---|---|
| Explicit v1 model + frozen v1 inputs | Replay the old equations unchanged. |
| Missing model discriminator but complete v1 frozen inputs | Treat as the named legacy v1 semantics; never reinterpret it as v2. |
| Missing discriminator and missing frozen crop/model inputs | Mark historical replay unsupported/qualified, preserve the stored summary and input artifact, and do not recompute or overwrite it from the current catalog/context. |
| Explicit but unknown model/parameter version | Report unsupported with an export path; preserve the stored summary. |
| New runs while v2 is not runnable | Continue using v1 with frozen v1 inputs; do not store a v2 placeholder summary. |
| New runs after the v2 daily reducer and acceptance gates pass | Use v2 and freeze every model-driving value, provenance, unit, event/method and fallback status. |

A migration cannot invent a user’s original measurements. If current run creation or playback cannot identify this state without changing summary semantics, that migration is part of the implementation gate; do not silently substitute live context.

### D2. Separate development, dry-matter production, and harvestable yield

Phenology uses crop-specific thermal response and fixed referenced stage/maturity targets. The source-defined accumulation method, start event, cultivar range and endpoint travel together. A run-window mean must not set a crop’s thermal target.

Daily net dry matter uses the LINTUL-family radiation-use-efficiency structure:

`ΔDM = RUE × intercepted PAR × supported stress factors`

The implementation must state units for every term and convert DLI/PAR explicitly. RUE is net dry-matter efficiency under its documented reference conditions; do not also subtract an unparameterized maintenance term and double-count respiration. Where maintenance/reserve dynamics are material (especially perennial/repeated-harvest crops), expose the limitation and defer the different lifecycle state contract to 02D. Dry matter and reproductive allocation/harvest index are separate. A catalog fresh-yield ceiling is not a biomass model or a harvest index.

Known zero usable PAR yields exactly zero sustained photosynthetic dry-matter gain. Germination reserves require explicit initial reserve state, finite reserve amount and an accounting event. Unknown PAR remains unknown and cannot be silently treated as sufficient. The result must be visibly incomplete/qualified or use a documented, provenance-tagged fallback only when its parameter source and domain are recorded. Fungi use a separate substrate/lifecycle model and never plant photosynthesis.

### D3. Use FAO-56 as the soil root-zone water method, within its supported input domain

For soil-grown crops, use the FAO-56 root-zone balance as the method reference: available water is based on AWC and effective rooting depth; stress begins relative to readily available water; water entering, extracted, draining and running off must reconcile in mm. Root-depth development and depletion fraction are crop/model parameters, not a universal 30 cm constant. The run must freeze those values.

This is a single effective root-zone storage model, not a layered Richards solver. If a necessary soil/media, root-depth, runoff, or water input is unavailable, expose the estimate/fallback and uncertainty. Do not call the current coarse nitrogen pool a solution-chemistry, pH, salinity or oxygen model. Soilless resource balance requires the 02B hydro/resource contract and must not be silently mapped to a soil bucket.

## D5. Parameter coverage and evidence classes

`quality/beta/evidence/model-coverage.json` is the initial inventory. Every built-in catalog crop is listed. Statuses distinguish:

- literature-derived thermal reference (not a validated full crop model);
- documented legacy-only value/fallback;
- missing v2 production/root-zone parameters;
- separate fungus model required;
- measured observations, reference-model agreement, and synthetic software fixtures.

Initial values in the existing thermal table are not evidence that the current biomass/yield model is accurate. The manifest includes source artifact SHA-256 hashes for downloaded source documents, the source edition/date/license or reuse terms, all available input/endpoint/unit details, unavailable data, valid domains, and explicit `UNVERIFIED` claims. Source PDFs remain external; only hashes and small derived parameters are recorded.

Calibration and holdout are separated by metric. OSU Croptime's reported error is computed on its model-development data and is not an independent holdout. The Michelon lettuce field results are a potential production holdout only if no parameter is fitted to them; the experiment identifies cultivar Green Wave and HS50 as the 50% ETc irrigation treatment. Its reported mean DLI and thermal sum are source summaries, not daily inputs, so the missing daily weather/light and soil series currently prevent an executable comparison. Cabbage thermal values already appear in the current parameter table and are parameter references, not held-out evidence. No claim is green until a reproducible source fixture, crop/cultivar, domain, sample size, metric, held-out error and fixture IDs are present.

## Numerical tolerances — independent review incorporated

No candidate model output has been compared. The preservation, thermal transcription, lettuce plant-mass and area-yield rounding, water-closure and zero-light checks below were preregistered and reviewed by the independent validator. These tolerances cover preservation, display rounding, and numerical closure only; none establishes predictive accuracy.

| Metric/check | Recorded tolerance | Basis and limits |
|---|---:|---|
| Supported frozen historical replay | Exact equality of the replayed state and summary | Compare only a record with complete frozen inputs and a supported explicit or identified legacy model version. Replay is the storage contract. |
| Unsupported historical record | Exact preservation of the stored summary and input artifact; no regenerated result is compared | Missing critical frozen data means unsupported/qualified. Preserve the prior record and do not recompute it from today's catalog or context. |
| Reproduction of a source thermal sum printed as an integer | ±0.5 °C·day after applying the source method, endpoint and stated unit conversion | Half of the displayed C·day unit, for transcription/reproduction only. It is not model-accuracy evidence. Do not compare incompatible accumulation methods or endpoints. |
| Lettuce fresh-mass means printed as whole g/plant | ±0.5 g/plant | Approved as table-rounding tolerance only, not an acceptable predictive-error band. The study has three plot replicates and samples 12 plants within each plot; the table reports means without raw plot values/variance. |
| Lettuce dry-mass means printed to 0.1 g/plant | ±0.05 g/plant | Approved as table-rounding tolerance only, not a predictive-error band. The 12 sampled plants are subsamples, not independent replicates. |
| Lettuce marketable area yield printed as `1.90 kg/m²` | ±0.005 kg/m² | Approved display-rounding tolerance only; half the 0.01 kg/m² display increment. It applies only to reproducing the published value, not to predictive accuracy. |
| Daily soil-water balance residual | ≤1e-6 mm per cell-day, conditional on unrounded internal pools | Use `residual = storage_start + inflow - uptake - drainage - runoff - storage_end`; include every boundary flux, retain unrounded state, report signed accumulated residual and maximum absolute daily residual separately. |
| Dry-matter state/partition closure | ≤1e-6 g DM/m²/day | Numerical-analysis check on additive mass transfers before output rounding; photosynthetic production, allocation and any explicit reserve transfer remain separately accounted. |
| Known zero usable DLI/PAR photosynthetic production increment | Exactly 0 g DM/m²/day | The production equation must return zero. Any seed or stored-reserve drawdown is a separate finite state transfer and cannot be counted as photosynthetic production. |
| Independent held-out harvest-date/yield/biomass error | No universal threshold proposed | Lock a source-specific threshold from measured precision or published independent error, then receive validator approval before comparison. Where daily inputs or variance are unavailable, mark comparison UNVERIFIED and do not invent a threshold. |

The independent validator reviewed and approved the displayed-value rounding tolerances for lettuce plant fresh/dry mass and marketable area yield, the ±0.5 °C·day transcription bound, and the water-balance bound subject to the stated unrounded-pool and residual-reporting conditions. These checks do not authorize predictive-accuracy claims. No candidate comparison has been run.

## Source-backed lettuce parameter fixture — 2026-10-27

This is a narrow software-integration fixture, not a complete biological parameter set or a candidate comparison.

- **Production reference:** Beccafichi et al. (2003), greenhouse butterhead lettuce cv. Rosalba in Perugia, reports above-ground dry-weight RUE `2.71 ± 0.030 g DM per MJ intercepted PAR`, estimated as the regression slope against cumulative PAR intercepted on a ground-cover basis (`R² = 0.99`). The study spans two seasons and densities of 5, 10, 15 and 30 plants/m². Preserve the reported `±0.030` as printed; it is not interpreted here as a confidence interval. The RUE applies to above-ground dry matter, not whole-plant biomass or marketable yield. It does not supply a generic fixed interception fraction or complete dynamic interception trajectory. This is a parameter reference only, not calibration evidence for a candidate. The publisher record and Perugia repository metadata were verified; the source PDF could not be retrieved in this environment, so the manifest records no binary digest and the parameter remains a source transcription pending artifact acquisition.
- **Root reference:** French et al. (2024) describe a lettuce root-depth profile adopted for direct-seeded Yuma iceberg/romaine field sites: initial depth 0.12 m at planting, root extension of 1.2 mm per °C·day after 200 cumulative GDD, root GDD base 4.5°C and upper threshold 28°C using single-sine horizontal cutoff. The 1.2 mm/°C·day rate is also consistent with Thorup-Kristensen (2006)'s abstracted lettuce estimate. The Yuma analysis selected 0.90 m as a site-specific effective-depth assumption after water-balance analyses (reasonable for 11 sites), not a generic or directly measured root maximum. Its p was 0.40 at ETc 5 mm/day and adjusted daily with FAO-56. FAO-56's generic lettuce row instead gives 0.3–0.5 m and p=0.30; these are separate domains and are not averaged or substituted into the Yuma profile. No transplant inference is made. The Yuma dataset is available from the corresponding author on request, not as a bundled daily fixture.
- **Executable fixture:** `LETTUCE-REFERENCE-PARAM-SYNTHETIC-INTEGRATION-01` composes the Michelon Green Wave thermal reference, Beccafichi Rosalba RUE reference, and French Yuma root reference only to exercise the deterministic reducer. Those sources use different cultivars, environments and start events. Synthetic inputs supply DLI 18 mol PAR m⁻² day⁻¹, intercepted PAR fraction 0.5, stress factor 1, initial available-water fraction 0.7 and harvest index 0.5. The equation-level result is 2 MJ intercepted PAR/m² and 5.42 g above-ground DM/m². The root trajectory is frozen as `thermal-linear-root-depth-v1`; its moving bucket boundary is `uniform-initial-awc-fraction-v1`, so each newly reached subsoil increment enters at the frozen initial available-water fraction and is included in the daily residual. This is an assumed moving control-volume boundary, not a measured soil profile or layered hydrology model. The fixture class is synthetic software evidence, not source reproduction, external reference agreement, or measured validation.
- **Separation:** The Green Wave thermal reference, greenhouse Rosalba production reference and direct-seeded Yuma root reference are different studies, cultivars, environments and start events. Their composition is deliberately labeled qualified and synthetic. It is not a catalog default, not used by new local run creation, and does not enable the v2 model for ordinary runs. New runs remain explicitly v1 while acceptance is incomplete. Michelon supplies the current thermal target, so it cannot be an independent full-model holdout. Any production-only holdout claim from Michelon would need metric-specific preregistration and complete daily inputs; those are unavailable.
- **Tolerance lock:** The manifest records rounding-only transcription bounds for RUE (`±0.005 g/MJ`), root rate (`±0.05 mm/°C·day`), GDD lag (`±0.5 °C·day`), initial depth (`±0.005 m`), root-GDD base (`±0.05°C`) and upper cutoff (`±0.5°C`). It preserves RUE's reported ±0.030 separately. The 0.90 m inferred cap has no transcription-accuracy tolerance. The synthetic water residual remains `≤1e-6 mm/cell-day` with the explicit root-growth storage term included. These tolerances do not set predictive accuracy and do not authorize a candidate comparison.

## Implementation checkpoint

The current implementation adds named v1/v2 frozen-input shapes, rejects persisted replay paths that would otherwise use a live crop catalog or soil context, and runs a qualified v2 daily path for explicitly supplied complete frozen inputs. It computes fixed-source thermal development, light-driven above-ground dry matter, harvestable dry matter, and a single effective FAO-56 root-zone balance. Historical frozen v2 profiles without root-growth fields retain their fixed-depth behavior. A separate optional root-development profile can advance root depth with its own frozen thermal method, and root-zone storage gained by the moving boundary is reported as an explicit inflow at the frozen initial available-water fraction; daily and accumulated water residuals include that flux. Root thermal accumulation, depth expansion, crop-root transpiration, and enclosure transpiration stop at the source maturity endpoint or after manual harvest; v1 postharvest behavior remains unchanged. FAO-56 depletion fraction adjusts around ETc 5 mm/day. The synthetic lettuce integration composes three distinct references: Michelon Green Wave transplant thermal targets, Beccafichi greenhouse Rosalba RUE, and French/Yuma direct-seeded iceberg/romaine roots. Their cultivar, environment, and start-event mismatch is explicitly qualified; this is not a catalog default or predictive model. Soil AWC source is frozen when known; legacy or missing provenance is retained as unknown and disclosed, and numeric AWC paired with SoilGrids classification-only provenance is explicitly qualified. Replant interventions preserve the cell's existing root-zone storage and residual history; any storage above a reduced new capacity is recorded as transition drainage and surfaced in the summary. PAR interception remains a synthetic fixed fraction in the fixture, ordinary daily runoff is explicitly assumed to be zero, and the single-bucket root boundary is not a layered soil profile; these limits are surfaced in qualified v2 output. Enclosed v2 climate transpiration is lagged potential ET using frozen, stage-independent root-zone Kc and the previous climate ET factor; it is not reduced by current root-zone Ks. Its CO₂ uptake term uses thermal progress times fixed PAR interception as a qualified leaf-area proxy, not measured LAI. With no environment-v1 climate state, enclosed natural DLI uses the frozen calibration cover transmission when present and the archetype default otherwise; frozen target lighting is included. If natural DLI is missing but a natural-plus-supplement enclosure has installed light, supplemental DLI is used only as a disclosed lower bound. Supplement-only worlds can use their known installed DLI directly. Pre-plant v2 cells do not transpire, contribute climate transpiration, or accumulate crop stress. At the source maturity endpoint, thermal accumulation is capped and dry-matter production stops; auto-harvest pays out on that endpoint day without the legacy three-day grace. V2 output remains qualified and explicitly UNVERIFIED; unsupported parameter sets preserve saved summaries and cannot replay. Runtime qualification reasons are deduplicated by crop and reason across simulated days. New local run creation remains explicitly v1 until complete source/domain-aligned parameter coverage and acceptance gates pass. Fresh-matter-only downstream summaries (campaign harvest and historical ensemble bands) reject or suppress v2 dry-matter output, and twin yield observations are left unscored with an explanation. Qualification displays expose the full assumption list. No predictive candidate comparison has been run. This is not an 02A completion claim: complete source/domain-aligned production/root parameters, dynamic canopy, sowing/transplant acceptance, broader stress integration, all-catalog coverage, and measured/reference acceptance fixtures remain outstanding.
