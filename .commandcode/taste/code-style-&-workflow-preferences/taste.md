# Code Style & Workflow Preferences
- Prefers committing current work before starting new features or major changes. Confidence: 0.9
- Values researching existing open-source solutions before building from scratch — explicitly directs agent to search and evaluate prior art. Confidence: 0.8
- Values gamification in tools — wants goals, loops, and "fun UX/UI" layered onto utilitarian applications (e.g., digital twins). Confidence: 0.8
- Prefers comprehensive, complete implementations ("full code and source code") rather than minimal or sketchy prototypes. Confidence: 0.7
- Communicates in an enthusiastic, stream-of-consciousness, playful style — prefers the agent to match this energy rather than being dry or overly formal. Confidence: 0.6
- Prefers interactive HTML forms (radio buttons, checkboxes, text areas) as a structured requirements-gathering tool when clarifying product direction — wants the agent to build a questionnaire and have the user fill it out rather than just chatting back-and-forth. Confidence: 0.7
- Prefers the agent to visually verify work by opening the running application (browser screenshots, tours, console checks) and demonstrating it works rather than just reporting completion. Explicitly asks to "report back once the preview is open and running." Confidence: 0.65
- Prefers the agent to verify the latest code is compiled, built, and the correct version is running before asserting features are available — will ask "Are you sure that you have me on the right page and you have compiled the code and built this version?" when features claimed don't match what's visible. Confidence: 0.7
- Uses concrete reference implementations (GitHub repos, screenshots) as quality benchmarks — provides them saying "this is what success looks like" and expects the agent to study the reference and match or exceed its quality, not just build a functional equivalent. Confidence: 0.75
- Prefers honest, transparent gap analysis when output falls short of expectations — values a direct comparison (e.g., a table enumerating every gap) and blunt acknowledgment of shortcomings over defensive explanations or premature claims of success. Confidence: 0.65
